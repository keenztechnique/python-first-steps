# 🤖 Telegram Quote Manager & Scraper Bot

Полнофункциональный асинхронный Telegram-бот для сбора, хранения, поиска и управления цитатами с поддержкой пагинации, аналитики и веб-скрапинга.

## 🛠 Технологический стек
* **Язык:** Python 3.12
* **Фреймворк бота:** `aiogram` v3 (Asyncio, FSM, Inline Keyboards)
* **База данных:** SQLite3 (параметризованные запросы, агрегация данных)
* **Парсинг данных:** `BeautifulSoup4`, `Playwright` (динамический скрапинг)
* **Переменные окружения:** `python-dotenv`
* **Контроль версий:** Git

## 📌 Ключевые возможности
- 🔍 **Поиск и фильтрация:** Поиск цитат по ключевым словам и авторам с защитой от SQL-инъекций.
- 📄 **Интерактивная пагинация:** Постраничный просмотр результатов через Inline-кнопки (`CallbackQuery`).
- 📊 **Аналитика и статистика:** Отображение общей статистики базы данных (`COUNT`, `DISTINCT`).
- 📝 **Машина состояний (FSM):** Пошаговое добавление новых цитат и авторов через диалоговые формы.
- 🕷 **Модуль скрапинга:** Автоматический сбор данных со статичных и динамических веб-страниц с экспортом в CSV/JSON и сохранением в БД.
- 🔒 **Безопасность:** Изоляция секретных токенов через `.env` и правила `.gitignore`.
